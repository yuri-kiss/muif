# Miyos (UI) Framework

The name of this library is **MUIF**, it stands for **M**iyos (**UI**) **F**ramework, but I have extended its purposes far beyond just UI!

This library is sort of like the google closure library but by me and with a bunch of differences.

## Development

You will need NodeJS v22 or later, and the [yarn package manager](https://yarnpkg.com/) to run / build this project.

To install yarn run `npm install -g yarn`, then run `yarn install` to install the dependancies.

---

This project uses [Mocha](https://mochajs.org/) and [Chai](https://www.chaijs.com/) for its testing, to run tests just run `yarn run test`.

To build the project run `yarn run build` to build for development, run `yarn run build:prod` to build for production.
